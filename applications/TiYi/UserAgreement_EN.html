1. Description of the Service

1.1 TiYi is a multi-protocol VPN client utility for connecting, on your device, to proxy nodes, remote configuration URLs, or VPN servers that you import yourself. Features may include, without limitation:

  • Multi-protocol connectivity: Shadowsocks (SS), VMess, VLESS, Trojan, Hysteria / Hysteria2 (Hy2), TUIC, WireGuard (WG), OpenVPN, and IKEv2, as supported in your build;
  • Profile import: remote configuration URLs, share links, Clash / sing-box configurations, OpenVPN files, pasted text, local files, URL schemes (such as ss, vmess, or vless), or (on iOS / iPadOS) QR-code scanning;
  • Node management: switching among nodes from a remote configuration and measuring latency;
  • Routing modes: rule, global, or direct;
  • System proxy and include-all-networks: injecting an HTTP proxy through the VPN tunnel, and optionally covering all network interfaces (on iOS, this may include cellular and local networks);
  • IKEv2: connecting through the system VPN API with the server and account details you enter;
  • Connection status, traffic statistics, diagnostic logs, and optional update checks.

Available features depend on your app version, device, operating system, and distribution channel. Packet tunneling relies on the system Network Extension; IKEv2 relies on system VPN. Capabilities may differ by OS version. We may update, adjust, or discontinue features from time to time.

Nodes, remote configurations, and servers are obtained and imported by you; your relationship with those third parties is governed by their own terms.
