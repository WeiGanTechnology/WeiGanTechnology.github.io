TiYi 隐私政策

更新日期：2026.9.14 · English

TiYi 是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的全协议 VPN 客户端。本隐私政策适用于 iOS、iPadOS 与 macOS 平台的 TiYi，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私政策与《TiYi 用户协议》共同构成您使用本服务的完整法律文件。

TiYi 是一款在您设备上运行的 VPN / 代理客户端，用于连接您自行导入的节点、远程配置链接或企业 VPN 服务器。我们不运营公共 VPN 节点，也不提供由我们托管的上网流量中转服务。配置档案主要保存在主应用的本地数据库中；当前用于连接的编译配置、隧道选项与部分偏好通过 App Group 与系统网络扩展在同一设备上共享。IKEv2 密码保存在系统钥匙串中。本服务当前不集成第三方广告 SDK，亦不提供应用内购买或付费订阅。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 配置、节点与远程配置链接。 您可通过粘贴文本、远程配置链接、文件导入、系统打开配置文件、URL Scheme（如 ss、vmess、vless 等），或（在 iOS / iPadOS 上）扫描二维码，导入 Shadowsocks、VMess、VLESS、Trojan、Hysteria / Hysteria2、TUIC、WireGuard、OpenVPN、Clash / sing-box 配置或节点分享链接（以实际版本支持为准）。相关配置原文、解析后的节点列表、远程配置地址、到期信息与您选择的节点，保存在设备本地，用于建立连接、切换节点与展示配置；其中当前连接所需的编译配置可能写入 App Group，供网络扩展读取。当您主动导入或更新远程配置时，本应用会向您提供的 URL 发起请求并下载配置；该请求发往您指定的第三方，而不是我们运营的服务器。请求中可能携带客户端标识（当前版本的 User-Agent 可能包含 clash-meta/tiyi 等字段，以实际版本为准），以便对方识别客户端类型。

1.2 VPN 连接、流量路由与 DNS。 在您授权系统 VPN / 网络扩展后，本服务可在设备上建立数据包隧道（Packet Tunnel）或系统 IKEv2 连接，并按您选择的规则、全局或直连模式转发网络流量。隧道内的网页、应用通信内容由操作系统与本地引擎按您的配置转发至您指定的节点或 VPN 服务器。应用为代理连接生成的默认配置可能包含第三方 DNS 解析地址（当前版本可能使用 1.1.1.1、223.5.5.5 等，以实际版本为准）；您自行导入的完整配置也可能指定其他 DNS。连接期间，域名解析请求可能发往上述解析服务、系统 DNS 或您配置的节点。我们不会在自有服务器上记录、存储或分析您的上网内容、访问记录、DNS 查询或完整流量日志，也无法从我们的服务器侧查看您的浏览内容。

1.3 IKEv2 凭证。 若您添加 IKEv2 配置，用户名、服务器地址及标识信息保存在本地配置中；密码写入系统钥匙串，并由系统 VPN 接口读取以建立连接。我们不会将 IKEv2 密码上传至我们的服务器。

1.4 测速、延迟检测与流量统计。 您在应用内对节点进行延迟检测时，本机会向该节点的主机与端口发起短时 TCP 连接探测。应用为代理连接生成的配置还可能包含自动测速出站，按设定间隔向您配置的测速 URL 发起连通性检测（默认可能为 https://www.gstatic.com/generate_204 等公开检测地址，您可在设置中修改）；该请求通常经相应节点发出，并由该检测服务的提供方按其自身政策处理。上传/下载字节等流量统计由本地网络扩展计算并在应用内展示，保存在设备本地。

1.5 诊断日志。 连接过程中，本地引擎与网络扩展可能生成诊断日志（如连接状态、错误信息），用于在应用内展示故障原因。日志保留在设备本地，我们不会自动将其上传至我们的服务器。

1.6 相机与剪切板（按您的操作）。 在 iOS / iPadOS 上，经您授权相机权限后，本服务可扫描节点或远程配置二维码，仅用于解析您对准的二维码内容。您点击「从剪贴板粘贴」时，本应用会读取当时的剪切板文本以导入配置；我们不会在后台读取或上传剪切板内容。

1.7 文件导入。 当您选择导入本地文件（如 `.json`、`.yaml`、`.yml`、`.ovpn`、`.conf`、`.txt`）时，本应用读取您选定文件中的配置文本。该读取仅在您主动选择文件后发生，文件内容保存在设备本地。

1.8 版本检查与评价提示（如适用）。 应用可能通过 Apple App Store 公开接口查询本应用是否有可用更新，或使用系统提供的评价提示能力。相关请求由 Apple 处理，我们不会因此收集您的支付凭证或广告标识符。

1.9 我们不会做的事。 本服务不要求您注册我们运营的应用内账号。我们当前不集成 Firebase、友盟、穿山甲、AdMob 等第三方广告或用户行为分析 SDK，亦不提供应用内购买、付费订阅或由我们运营的云端账号同步。我们不会在您未授权时开启 VPN，不会申请相册、通讯录、麦克风、定位、蓝牙等与核心连接功能无关的敏感权限（以实际版本为准），亦不会将您的配置、凭证或上网内容上传至我们的服务器。

1.10 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • VPN / 代理配置与节点信息（含远程配置 URL、节点地址、端口、协议参数、证书/密钥材料、Clash 或 sing-box 配置文本）：在设备本地处理，目的为导入、保存并建立您指定的连接，方式为主应用本地数据库、文件，以及向网络扩展共享当前连接所需的编译配置，范围为您导入或生成的配置。我们不将其上传至我们的服务器。
  • IKEv2 账号与密码：用户名等保存在本地配置，密码写入系统钥匙串，目的为使用系统 VPN 接口建立 IKEv2 连接，方式为本地存储与钥匙串，范围为您填写的该条配置凭证。
  • 经隧道转发的网络流量：仅在您的设备与您指定的节点/VPN 服务器之间按配置转发，目的为提供 VPN / 代理连接，方式为系统网络扩展与本地引擎，范围为当前连接会话。我们不在自有服务器上保存您的上网内容或访问记录。
  • 远程配置更新请求：仅在您导入或刷新远程配置链接时发往您提供的 URL，目的为获取最新节点列表，方式为 HTTPS/HTTP 请求（可能携带客户端 User-Agent），范围为该次请求及返回的配置内容。该第三方如何处理请求由其自身政策决定。
  • DNS 查询：在 VPN 连接期间按配置进行域名解析，目的为建立连接与转发流量，方式为本地引擎及系统 DNS 设置，范围为待解析的域名。默认配置可能将部分查询发往 1.1.1.1、223.5.5.5 等第三方解析服务（以实际版本及您导入的配置为准）。我们不在自有服务器上保存您的 DNS 查询记录。
  • 测速与延迟探测：向节点主机/端口发起短时 TCP 探测，或向您配置的测速 URL 发起连通性检测，目的为展示延迟、选择节点或维持自动测速，方式为本机探测或经节点发出的网络请求，范围为实现测速所需的最小探测。
  • 流量统计与连接状态：在设备本地处理，目的为展示上传/下载量与连接时长，方式为本地计数，范围为非用于识别您身份的统计数值。
  • 诊断日志：在设备本地保存，目的为排查连接失败原因，方式为本地日志缓冲，范围为引擎与扩展输出的状态/错误信息。
  • 应用设置与偏好（如选中的配置、路由模式、是否包含所有网络、系统代理开关、测速 URL）：在设备本地（含 App Group）处理，目的为记住您的连接偏好，方式为本地存储，范围为应用配置项。
  • 二维码内容：仅在您主动扫描时于设备本地解析，目的为导入节点或远程配置，方式为相机预览与本地解码，范围为当前对准的二维码。我们不保存相册或持续录像。
  • 剪切板文本：仅在您点击粘贴导入时读取，目的为导入配置，方式为系统剪切板接口，范围为当时剪切板中的文本。不在后台读取或上传。
  • 用户选定的配置文件：经您授权读取后导入，目的为解析 VPN / 代理配置，方式为系统文件选择器，范围为您选中的单个文件内容。
  • 设备与系统信息（如设备型号、系统版本、应用版本）：目的为功能兼容、VPN 扩展状态与版本检查，方式为系统接口读取或向 App Store 公开接口发起查询，范围为功能实现所需参数。
  • 网络连接：用于远程配置更新、测速、DNS 解析、版本检查、以及与您指定节点建立 VPN / 代理连接，目的为实现上述功能，方式为系统网络与网络扩展，范围为相关必要网络请求或隧道通信。
  • 本地网络：用于节点延迟检测及本地代理相关通信，目的为测速与在本机提供代理能力，方式为系统本地网络接口，范围为实现该功能所需的本机/局域网通信。
  • 日历、相册、通讯录、短信、本机号码、通话记录、位置信息：不收集。
  • 广告标识符（IDFA 等）：本服务当前不集成广告 SDK，不为广告投放目的收集上述标识符。
  • 支付与付费订阅信息：不收集（本服务当前不提供应用内购买或付费订阅）。
2. 第三方服务

本节说明本服务可能涉及的第三方服务。不同系统版本实际可用的能力可能有所差异。

2.1 Apple 服务（iOS / iPadOS / macOS）

本服务使用 Apple 提供的网络扩展（Network Extension / Packet Tunnel）、系统 VPN（含 IKEv2）、钥匙串（Keychain）、App Group，以及可选的相机、本地网络、App Store 更新查询与系统评价提示（StoreKit）。VPN 配置由系统保存并由您在系统设置中管理。支付相关能力当前未用于内购。相关数据处理受 Apple 政策约束。
Apple 隐私政策：https://www.apple.com/legal/privacy/

2.2 您指定的节点、远程配置源、DNS 与测速地址

当您导入或刷新远程配置、连接节点、解析域名或进行测速时，网络请求会发往您提供或选择的第三方服务器，以及应用默认配置中的第三方 DNS / 连通性检测地址（当前版本可能包括 1.1.1.1、223.5.5.5 及 https://www.gstatic.com/generate_204 等，以实际版本为准）。这些服务由相应提供方运营，我们无法控制其日志、留存或隐私实践。请在导入前确认来源可信，并阅读该提供方的条款与隐私政策。

2.3 操作系统与本地引擎

本服务在网络扩展中使用本地 VPN / 代理引擎处理您导入的配置，并使用操作系统提供的本地存储、钥匙串、网络、文件选择、相机与界面渲染能力。除发往您指定第三方或 Apple 的必要请求外，我们不会将您的配置、凭证或上网内容上传至我们自有的云端服务器。当前版本不提供由我们运营的云端同步；如未来启用 iCloud 或其他同步能力，我们将依法更新本政策。

3. 付费与商业化

当前版本的 TiYi 不提供应用内购买、付费订阅或广告解锁。若未来版本引入付费功能或广告，我们将依法更新本隐私政策与用户协议，并在必要时征得您的同意。

4. 设备权限调用

TiYi 仅在实现 VPN 连接、配置导入与测速所必需时申请权限。我们会在系统权限弹窗或系统设置引导中征求您的同意；您拒绝授权仅会影响对应功能。以下按平台分别说明。

iOS / iPadOS

VPN / 网络扩展

用于安装并启用数据包隧道或系统 IKEv2 配置，从而按您导入的节点建立加密连接。未授权时无法连接。

相机

用于扫描节点或远程配置二维码。未授权时仍可通过粘贴、链接或文件导入配置。

本地网络

用于节点延迟检测及本地代理相关通信。

网络

用于导入或更新远程配置、测速、域名解析、检查 App Store 更新，以及与您指定的节点建立连接。

剪切板（按需读取）

仅在您主动点击粘贴导入时读取剪切板文本。

文件访问（用户选定）

用于在您选择本地配置文件后读取其内容并导入。

macOS

VPN / 网络扩展、本地网络、网络、剪切板粘贴与文件导入的使用目的与上文相同。当前 macOS 版本不提供相机扫码；您可通过粘贴、远程配置链接或文件导入配置。

您可以随时在系统「设置」中关闭 VPN、撤回相机或本地网络权限，或卸载应用以停止相关处理。

5. 管理您的个人信息

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本隐私政策中「如何联系我们」章节中所述方式与我们取得联系，并行使您的相关权利。

您可通过删除应用内配置、在系统设置中移除 VPN 配置、卸载应用或清除应用数据的方式，停止处理并移除设备本地保存的配置、偏好与日志。IKEv2 密码随相应配置删除从钥匙串中移除。对于由 Apple 或您指定的第三方节点/远程配置源/DNS 或测速服务处理的信息，您也可通过相应提供方的设置或政策行使权利。

6. 信息存储地点及期限

6.1 您通过本应用产生的配置档案、节点列表、路由偏好、流量统计与诊断日志，主要在您的设备本地处理与保存；当前连接所需的编译配置与部分偏好可通过 App Group 与网络扩展共享；IKEv2 密码保存在系统钥匙串。当前版本不提供由我们运营的云端同步服务。

6.2 远程配置更新、DNS 解析、测速及与节点之间的隧道通信发生在您的设备与相应第三方之间；版本检查相关请求由 Apple 按照其政策在相应基础设施中处理，可能涉及您所在国家或地区以外的服务器。

6.3 除法律法规另有规定外，我们对信息的保存期限为为实现处理目的所必要的最短时间。您卸载应用、删除配置或主动清除数据后，相应本地信息将被删除，但已写入系统 VPN 偏好或已发往第三方的请求，仍受相应系统或第三方机制约束。
