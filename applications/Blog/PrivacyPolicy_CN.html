我博客 隐私政策

更新日期：2026.9.4 · English

我博客（英文名称：MineBlog）是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的博客园（Cnblogs）第三方客户端。本隐私政策适用于 iOS、iPadOS、macOS 与 visionOS 平台的我博客，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私政策与《我博客 用户协议》共同构成您使用本服务的完整法律文件。

我博客本身不运营独立的用户账号体系。您可通过博客园 OAuth 登录已有博客园账号，以使用查看关注动态、管理收藏、发布闪存、参与博问与班级等功能；未登录时，您仍可浏览部分公开内容。登录凭证、访问令牌、MetaWeblog 图床令牌、界面偏好、草稿与缓存数据主要保存在您的设备本地。本服务当前不集成第三方广告 SDK，亦不以展示广告作为核心功能的解锁条件。本服务当前不收取应用内订阅或买断费用。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 博客园账号登录。 当您选择登录时，应用会通过内嵌网页引导您前往博客园官方授权页面完成 OAuth 授权。授权成功后，我们会接收授权码并换取访问令牌（access token）与刷新令牌（refresh token），用于代表您调用博客园开放接口。我们可能从博客园接口获取您的昵称、头像、博客地址、用户标识等账户资料，用于在应用内展示个人主页与管理相关功能。上述账号注册、实名认证、密码找回、账号注销等事宜由博客园按其规则处理；您可在博客园官网或账户设置中办理。

1.2 匿名浏览。 在未登录或令牌失效时，应用可能通过博客园开放接口的客户端凭证（client credentials）获取匿名访问令牌，以便您浏览部分公开内容（如博文、新闻、知识库、博问等）。该过程不涉及您向我们提供个人身份信息。

1.3 内容浏览与搜索。 为向您展示首页信息流、博文详情、新闻、知识库、博问、闪存动态、班级作业/公告/投票及搜索结果，应用会向博客园服务器请求相应内容，并在设备本地进行排版展示与缓存。浏览过程中涉及的作者昵称、头像、文章正文、评论等内容通常来自博客园平台，其处理亦受博客园规则约束。

1.4 内容发布与互动。 当您登录后发布闪存、提问、回答、评论、参与投票、提交班级作业，或（在具有管理权限时）发布班级作业、公告与投票时，您主动输入的文字、链接、图片及相关元数据（如可见范围）将通过博客园开放接口或相关服务接口提交至博客园服务器，以便在博客园平台展示或完成互动。我们不会在自有服务器上长期存储您发布的完整内容副本。

1.5 图片选择与上传。 当您发布闪存并选择图片时，应用会请求访问您选中的相册图片。所选图片将通过博客园 MetaWeblog 接口上传至博客园图床，并返回图片链接用于发布；上传时会优先使用您在设置中配置的 MetaWeblog 访问令牌，若未单独配置，则可能使用当前登录获得的 OAuth 访问令牌完成校验。若您未登录或未绑定博客，图片可能无法上传。我们不会将您相册中的其他图片上传至我们的服务器。

1.6 收藏与本地偏好。 您的收藏可通过博客园接口获取、添加、编辑或删除；关注动态及相关统计信息主要通过博客园接口获取，用于在登录后展示您已关注博主的内容（本应用当前不提供关注或取消关注操作）。主题色、外观模式、语言偏好、搜索分类偏好、未发布草稿及界面设置主要保存在设备本地，用于改善您的使用体验。

1.7 本地缓存与安全存储。 为提升加载速度，应用可能在设备本地缓存图片、接口响应等内容；OAuth 令牌、刷新令牌及 MetaWeblog 令牌优先保存在系统钥匙串（Keychain）中，在钥匙串不可用时可能回退至本地偏好存储。您可在应用设置中清理缓存；退出登录将清除本地登录状态相关数据。

1.8 我们不会做的事。 本服务当前不集成 Firebase、友盟、穿山甲、AdMob 等第三方广告或用户行为分析 SDK。我们不会在自有服务器上运营独立的用户账号数据库，亦不会将您的短信、通话记录、通讯录、精确位置、相机拍摄内容（除您主动选择发布的相册图片外）上传至我们的服务器。本服务当前不以远程推送通知作为核心功能。

1.9 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • 博客园账户信息（昵称、头像、博客地址、用户标识等）：在您登录后通过博客园接口获取，目的为展示个人资料与提供需登录功能，方式为接口调用与本地展示，范围为博客园返回的必要字段。
  • OAuth 访问令牌与刷新令牌：在您授权登录后获取，目的为维持登录状态并调用博客园接口，方式为钥匙串或本地安全存储，范围为令牌本身及到期信息。
  • MetaWeblog 访问令牌 / OAuth 访问令牌：MetaWeblog 令牌由您主动在设置中配置；若未配置，上传图片时可能使用当前登录获得的 OAuth 访问令牌，目的为上传闪存图片至博客园图床，方式为本地存储与接口调用，范围为完成上传所必需的凭证信息。
  • 您发布或提交的内容（文字、链接、图片等）：由您主动创建，目的为在博客园平台发布闪存、提问、回答、评论、作业或参与投票，方式为提交至博客园服务器，范围为您确认发布的内容。
  • 相册图片：经您通过系统选择器主动选取，目的为作为闪存配图上传，方式为读取所选图片并上传至博客园图床（使用 MetaWeblog 或 OAuth 令牌），范围为您选中的图片文件。
  • 浏览内容缓存：在设备本地处理，目的为加速内容展示与减少重复请求，方式为本地磁盘缓存，范围为接口响应与图片缓存，可在设置中清理。
  • 界面偏好与草稿：在设备本地处理，目的为保存主题、语言、外观及未发布草稿，方式为本地偏好存储，范围为相关设置项与草稿文本。
  • 设备与系统信息（如设备型号、系统版本、应用版本）：目的为界面适配与功能兼容，方式为系统接口读取，范围为功能实现所需参数。
  • 网络连接：在浏览、搜索、登录、发布、上传图片及刷新令牌时使用，目的为与博客园及相关服务通信，方式为 HTTPS 网络请求，范围为完成上述功能所必需的数据交换。
  • 剪切板：仅在您主动使用复制标题、复制链接或复制文本等功能时写入内容，本应用不会读取剪切板。
  • 相机、麦克风、通讯录、精确位置、日历、通话记录：不收集。
  • 广告标识符（IDFA 等）：本服务当前不集成广告 SDK，不为广告投放目的收集上述标识符。
2. 第三方服务

本节说明本服务可能涉及的第三方服务。不同系统版本实际可用的能力可能有所差异。

2.1 博客园（Cnblogs）

本服务的核心内容、账号体系、发布、评论、收藏、关注动态查看、班级、图床上传等功能均依赖博客园提供的网站、OAuth 授权、开放接口（api.cnblogs.com）、MetaWeblog 接口（rpc.cnblogs.com）及相关服务。您登录、发布内容、浏览他人内容时，相关信息将由博客园按其隐私政策与服务条款处理。
博客园相关说明请参阅其官方网站及开放接口文档：https://www.cnblogs.com/、https://api.cnblogs.com/help

2.2 Apple 服务（iOS / iPadOS / macOS / visionOS）

本服务使用 Apple 提供的系统界面组件、钥匙串（Keychain）、相册选择器（PhotosPicker）、网络、本地存储及应用分发能力。若未来版本启用推送通知、CloudKit 或其他 Apple 能力，相关处理将受 Apple 政策约束。
Apple 隐私政策：https://www.apple.com/legal/privacy/

2.3 操作系统能力

本服务主要使用操作系统提供的本地存储、网络、WebView（用于博客园 OAuth 登录页）与界面渲染能力。除向博客园提交您主动发起的内容与接口请求外，我们不会在自有云端服务器上集中存储您的个人数据。

3. 设备权限调用

我博客仅在实现相关功能所必需时申请权限。我们会在系统权限弹窗或功能引导中征求您的同意；您拒绝授权仅会影响对应功能。以下按平台分别说明。

iOS / iPadOS / visionOS

相册（照片）

用于在您发布闪存时选择配图。仅在您主动点击添加图片并选取后读取相应图片，不会扫描或上传您的整个相册。

网络

用于登录、浏览内容、搜索、发布、上传图片、刷新令牌及加载网页资源。

macOS

可能提供与 iOS / iPadOS 相对应的内容浏览、发布与管理能力；相册、网络权限的使用目的与上文相同。具体以您所使用版本为准。

您可以随时在系统「设置」或应用权限管理中管理本应用的权限。退出登录、清理缓存或卸载应用，可停止相应数据处理并删除设备本地保存的缓存与登录状态（已提交至博客园的内容仍受博客园规则约束）。

4. 管理您的个人信息

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本隐私政策中「如何联系我们」章节中所述方式与我们取得联系，并行使您的相关权利。

对于由博客园处理的信息（包括账号资料、已发布内容、评论、收藏等），您应通过博客园官方渠道查询、更正或删除。您可在应用内退出登录，或在博客园账户设置中管理账号与注销事宜。您可通过应用设置清理本地缓存，通过卸载应用删除设备本地的令牌、草稿与缓存数据。

5. 信息存储地点及期限

5.1 OAuth 令牌、MetaWeblog 令牌、界面偏好、草稿与内容缓存主要保存在您的设备本地；我们当前不提供由自有服务器运营的云端账号同步服务。

5.2 您通过本应用发布或提交至博客园的内容、评论、收藏及账户资料，由博客园按照其政策在相应基础设施中存储和处理，可能涉及您所在国家或地区以外的服务器。

5.3 本地缓存的保存期限为实现加速展示所合理必要的时间，您可随时在设置中清理。退出登录后，本地登录凭证将被清除；已发布至博客园的内容不因退出登录而自动删除。

5.4 除法律法规另有规定外，我们对本地信息的保存期限为为实现处理目的所必要的最短时间。您卸载应用后，设备本地的令牌、缓存与草稿通常将被删除。

6. 未成年人保护

若您为未成年人，请在监护人指导下阅读本政策并使用本服务，取得监护人同意后再进行博客园账号登录与内容发布。博客园账号注册与使用亦应遵守博客园及适用法律对未成年人的相关规定。
