1. Description of the Service

1.1 DevLocation is a GPS location simulation tool for iOS development and testing. Main features include, without limitation:

  • Single-point mode (macOS): pick coordinates on a map and send simulated locations to connected iOS devices;
  • Route mode (macOS): simulate movement along waypoints with walk, run, cycle, and drive speed profiles, including loop playback;
  • Favorites and history (macOS): save frequently used places, routes, and visit history for quick reuse;
  • Maps and search: map picking, quick city jumps, and coordinate copying (macOS); address search is mainly available on macOS;
  • GPX import/export (macOS): import or export route files;
  • Device connection (macOS): discover and connect iOS devices with Developer Mode enabled over USB or the local network;
  • Companion app (iOS / iPadOS / visionOS): view simulation status, map display, remote stop, and sync state with the Mac control app over the local network (Bonjour);
  • Desktop capabilities (macOS): menu bar access, runtime logs, optional tunnel services, background agent, and optional road routing.

Actual features depend on the version, device, operating system, and system developer capabilities available to you. We may update, adjust, or discontinue features from time to time.

1.2 The Service requires Developer Mode on the target iOS device and a trusted USB or local-network connection. You must grant relevant system permissions for USB, local network, location, and file access where needed. Denying a permission may disable the related feature but does not necessarily prevent use of unrelated features (subject to your version).

1.3 The Service does not require you to register an in-app account with us. Simulation data, favorites, history, and settings are stored mainly on your devices. The current version does not provide cloud account sync operated by us.

1.4 Features vary by platform, for example:

  • On macOS, the app provides full control capabilities including device management, map control, route playback, GPX import/export, logs, and menu bar access;
  • On iOS / iPadOS / visionOS, the app mainly provides companion status display, map viewing, and remote stop;
  • Some advanced or internal builds may include a standalone mode that is generally not distributed publicly on the App Store.
