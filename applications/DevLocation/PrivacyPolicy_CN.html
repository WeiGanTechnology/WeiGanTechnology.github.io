DevLocation 隐私政策

更新日期：2026.8.31 · English

DevLocation 是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的 GPS 定位模拟开发工具，用于在已连接的 iOS 设备上模拟 GPS 定位，辅助应用开发与测试。本隐私政策适用于 iOS、iPadOS、macOS 与 visionOS 平台的 DevLocation，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私政策与《DevLocation 用户协议》共同构成您使用本服务的完整法律文件。

本服务以 Mac 端为主要控制端，通过 USB 或本地网络连接 iPhone 等 iOS 设备并下发模拟定位；iOS / iPadOS / visionOS 伴侣端用于查看模拟状态、地图展示及远程停止等。模拟坐标主要在您的设备本地处理；收藏地点、路线、历史记录与运行日志主要在 macOS 设备本地处理。我们不会将上述数据上传至我们自有的云端服务器。本服务当前不集成第三方广告 SDK，亦不提供由我们运营的应用内账号或云端同步服务。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 核心应用功能。 为实现单点定位、轨迹模拟、设备连接与管理、收藏与历史记录、GPX 导入导出、地图选点与地址搜索等功能，我们会在您的设备本地处理模拟坐标、途经点、速度参数、收藏地点、已保存路线、访问历史、设备名称与 UDID（用于识别已连接设备）、运行状态及界面偏好。其中，设备连接管理、收藏与历史、GPX 导入导出及地址搜索主要在 macOS 版本中提供；伴侣端主要用于展示同步后的模拟状态。上述数据主要用于在您的设备上完成定位模拟与状态展示，我们不会将其用于识别您的个人身份，亦不会将完整数据库存档上传至我们的服务器。

1.2 本地偏好设置与跨端同步。 我们会在您的设备本地保存部分设置（如地图样式、模拟模式、隧道与后台代理状态、界面偏好等）。在 macOS 与 iOS / iPadOS / visionOS 伴侣端之间，模拟状态摘要（如是否正在模拟、当前坐标、设备名称等）主要通过 本地网络（Bonjour） 同步；远程停止等指令亦通过该本地连接发送。App Group 用于在同一设备上的本应用内部保存状态与指令（如适用），不会在 Mac 与 iPhone 之间自动跨设备同步。上述通信均在您的本地网络或本机内进行，不会上传至我们的服务器。

1.3 地图与地址搜索。 当您使用地图展示功能时，相关能力由 Apple MapKit 等系统地图服务提供。在 macOS 版本中，当您使用地址搜索或地点检索时，我们可能向 Apple 发送您输入的搜索关键词或地图区域信息，以获取搜索结果与地图瓦片。Apple 对相关数据的处理受其政策约束。

1.4 可选的道路规划（OSRM）。 在 macOS 版本中，若您主动开启道路规划相关选项，应用可能将起点与终点的经纬度坐标发送至公共 OSRM 路由服务（如 router.project-osrm.org），以获取沿道路的途经点。我们仅发送完成功能所必需的坐标参数，不会发送您的设备标识、联系人或其他无关信息。该服务由第三方运营，其数据处理受其自身政策约束。

1.5 诊断与故障排查。 在 macOS 版本中，应用可能在本地生成运行日志或诊断摘要，用于设备连接、隧道与模拟过程排查；您可主动查看或复制相关日志。此类信息默认不上传至我们的服务器。

1.6 GPX 与配对文件（如适用）。 在 macOS 版本中，当您导入或导出 GPX 路线文件时，相关文件由您主动选择，保存在设备本地或您指定的文件夹中。在高级/内部构建中，您亦可导入开发者配对文件。我们不会主动读取或上传您的其他个人文件。

1.7 我们不会做的事。 本服务不要求您注册我们运营的应用内账号。我们当前不集成 Firebase、友盟、穿山甲、AdMob 等第三方广告或用户行为分析 SDK。我们不会在后台批量读取您的相册、通讯录、短信、通话记录或本机号码，亦不会申请相机、麦克风等与核心功能无关的敏感权限（以实际版本为准）。

1.8 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • 模拟坐标与路线数据：在设备本地处理，并可能通过 USB 或本地网络发送至您已连接且已授权的 iOS 设备，目的为实现 GPS 定位模拟，方式为本地处理与设备间通信，范围为当前模拟会话相关的坐标、速度与途经点。
  • 收藏地点、路线与历史记录：在 macOS 设备本地处理，目的为保存与管理常用位置与路线，方式为本地存储，范围为应用相关的地点名称与坐标信息。
  • 设备连接信息（如设备名称、UDID、连接方式）：在设备本地处理，目的为识别与管理已连接 iOS 设备，方式为系统开发者服务接口读取，范围为连接管理所需参数。
  • 模拟状态摘要：主要通过 Bonjour 在您的 Mac 与 iOS 设备间于本地网络同步；App Group 用于同一设备上的本应用内部状态保存（如适用），目的为伴侣端展示状态与远程控制，方式为局域网通信或本机共享，范围为模拟状态、坐标摘要与主机名称等必要字段。
  • 地图搜索关键词（macOS）：发送至 Apple MapKit，目的为地址与地点检索，方式为系统地图服务请求，范围为您输入的搜索词或地图区域。
  • 道路规划坐标（可选，macOS）：在您开启相关选项时发送至 OSRM 公共服务，目的为生成沿道路轨迹，方式为本应用发起的 HTTPS 请求，范围为起终点经纬度。
  • Mac 当前位置（可选）：在您授权定位权限并使用「当前位置」功能时读取，目的为在地图上快速跳转，方式为系统定位接口读取，范围为一次性坐标，不上传至我们的服务器。
  • 应用设置与偏好：在设备本地处理，目的为记住界面与功能偏好，方式为本地存储，范围为应用配置项。
  • 剪切板（macOS）：本应用仅在您主动触发复制操作时，将您选择的坐标或文本写入系统剪切板，不会在后台读取或上传剪切板内容。
  • 日历、短信、通讯录、本机号码、通话记录：不收集。
  • 广告标识符（IDFA 等）：本服务当前不集成广告 SDK，不为广告投放目的收集上述标识符。
2. 第三方服务

本节说明本服务可能涉及的第三方服务。不同平台实际接入的服务可能有所差异。

2.1 Apple 服务（iOS / iPadOS / macOS / visionOS）

本服务使用 Apple MapKit 提供地图展示；在 macOS 版本中亦用于地点搜索，并通过 Apple 开发者服务接口与已连接的 iOS 设备通信。相关数据处理受 Apple 政策约束。
Apple 隐私政策：https://www.apple.com/legal/privacy/

2.2 OSRM 道路规划服务（macOS，可选）

当您主动开启道路规划相关选项时，应用可能向公共 OSRM 实例（如 Project OSRM 演示服务）发送起终点坐标以获取路线几何信息。该服务由第三方社区或组织运营，我们不对其可用性、准确性或数据处理行为作担保。您可随时关闭相关选项以停止向该服务发送请求。

2.3 操作系统与开源组件

本服务主要使用操作系统提供的 USB、本地网络、定位、文件选择与界面渲染能力；macOS 版本可能内置或调用开源设备通信组件（如 pymobiledevice3 相关运行时）在本地与您的 iOS 设备交互。除您主动启用的地图搜索与道路规划外，我们不会将您的模拟数据库上传至我们自有的云端服务器。

3. 付费服务

本服务当前以开发工具形式提供，不收取应用内订阅或买断费用，亦不集成应用商店内购以解锁核心功能。若未来版本引入付费能力，我们将依法更新本隐私政策，并在必要时征得您的同意。

5. 管理您的个人信息

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本隐私政策中「如何联系我们」章节中所述方式与我们取得联系，并行使您的相关权利。

对于由 Apple、OSRM 或其他第三方处理的信息，您也可通过相应提供方的设置或政策行使权利。您可通过删除收藏与历史记录、清除应用数据或卸载应用的方式，移除设备本地保存的模拟数据与设置。

6. 信息存储地点及期限

6.1 您通过本应用产生的模拟坐标主要在您的设备本地处理与保存；收藏地点、路线、历史记录与运行日志主要在 macOS 设备本地处理与保存；当前版本不提供由我们运营的云端同步服务。

6.2 地图搜索与可选道路规划相关数据由 Apple、OSRM 等第三方按照各自政策在相应基础设施中存储和处理，可能涉及您所在国家或地区以外的服务器。

6.3 除法律法规另有规定外，我们对信息的保存期限为为实现处理目的所必要的最短时间。您卸载应用或主动清除数据后，相应本地信息将被删除。
