CaptureLink 隐私政策

更新日期：2026.8.7

CaptureLink 是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的复古游戏模拟应用。本隐私政策适用于 iOS、iPadOS、macOS 与 Android 平台的 CaptureLink，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私政策与《CaptureLink 用户协议》共同构成您使用本服务的完整法律文件。

在 iOS / iPadOS 版本中，非 VIP 用户适用广告与使用次数相关规则。当系统判定您所在地区为中国大陆时，广告通过穿山甲 GroMore 聚合服务提供（含穿山甲与优量汇）；在其他地区使用 Google AdMob。VIP 通过 Apple 内购提供。macOS 版本不展示广告、不设每日启动次数限制，但启动游戏需要有效的 VIP 订阅。

Android 版本通过 Google Play 等应用商店分发时，Premium / VIP 订阅与买断由 Google Play 结算提供；通过 OPPO、vivo、360 手机助手等国内应用商店分发时，非 Premium / VIP 用户可能通过 穿山甲 GroMore 聚合服务展示广告（详见下文第 2.3 节），Premium / VIP 订阅与买断由相应应用商店结算提供。游戏 ROM、存档与相关数据主要在设备本地处理，当前不提供 iCloud 同步。在初始化任何广告 SDK 前，我们会征得您的同意。

Android 中国大陆分发版本应用内提示（与首次启动弹窗一致）

欢迎使用 CaptureLink。请阅读并充分理解《用户协议》和《隐私政策》。

一、核心功能
为提供 ROM 导入、游戏模拟、联机对战等功能，我们会在您使用相关功能时申请存储和网络权限。相关数据主要在本地处理。

二、广告服务（仅在您点击「同意」后初始化）
为展示广告、统计广告效果及防范作弊，本应用通过穿山甲 GroMore 聚合服务接入第三方广告 SDK，包括「穿山甲广告 SDK」「优量汇 Android SDK」与「抖音SDK（安卓版）」。每日可免费启动游戏 2 次，观看激励视频可额外获得 2 次启动机会。

若您不同意广告服务相关条款，可选择「不同意，仅使用核心功能」：我们不会在未获您同意时初始化广告 SDK。在此模式下，您可使用手柄设置等基础功能；游戏启动、游戏库（校准）及每日启动配额需在同意广告服务后使用。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 核心应用功能。 为实现游戏模拟、存档管理、联机、手柄支持等功能，我们会在您使用相关功能时，通过系统接口调用蓝牙、麦克风、本地网络及 iCloud 能力（Android 上为存储、网络、Wi-Fi 等相关能力）。在 iOS / iPadOS 上，保存游戏内截图时可能请求相册写入权限；在 Android 上，截图主要保存在应用存储空间，或在您授权时将图片保存至相册。您导入的游戏 ROM、存档、截图等内容在设备本地或您主动选择的服务中处理。在您主动发起的联机过程中，游戏数据可能在您的设备与本地网络中的其他玩家设备之间直接传输。可选的 iCloud 存档同步（仅 iOS / iPadOS / macOS）与 RetroAchievements（仅 VIP / Premium 订阅用户）按各平台能力提供。我们不会将上述数据用于识别您的个人身份。

1.2 本地偏好设置。 我们会在您的设备本地保存部分设置（如主题、使用次数配额、VIP 状态标记及模拟器偏好等），用于应用正常运行。

1.3 广告地区判定（iOS / iPadOS；Android 在接入广告且需要判定时亦可能适用）。 为选择适当的广告服务商，应用可能向第三方 IP 地理位置服务（ipinfo.io）请求您的国家或地区代码。该请求可能向该服务暴露您的 IP 地址。若请求失败或尚无已存储值，我们可能回退至设备语言（例如简体中文对应中国大陆）。所得地区代码保存在您的设备本地。

1.4 封面查询。 为展示游戏封面，应用可能将基于 ROM 文件名清理后的游戏标题发送至 IGDB（通过 Twitch OAuth）及 Apple iTunes Search API 等第三方服务。我们不会发送 ROM 文件内容。获取的封面图片缓存在您的设备本地。

1.5 可选的第三方登录。 若您为 VIP / Premium 订阅用户并选择使用 RetroAchievements，您的用户名与认证令牌将保存在设备安全存储中（iOS / macOS 为钥匙串，Android 为系统密钥库等），并传输至 RetroAchievements 服务器以完成登录与成就同步。我们不运营 RetroAchievements，其数据处理受其自身政策约束。

1.6 我们不会做的事。 本服务不要求您注册应用内账号。在 iOS / iPadOS 上，非 VIP 用户可在使用次数限制内使用核心模拟功能。在 macOS 上，启动游戏需要有效的 VIP 订阅。在 Android 上，核心模拟功能不要求注册账号；Premium / VIP 权益通过 Google Play 结算或国内应用商店结算等方式解锁（如适用）。我们不提供、不包含且不分发任何受版权保护的游戏 ROM 或其他第三方内容。

1.7 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • 设备标识符（IDFV；经授权时的 IDFA；Android 可能涉及 OAID、Android ID）：在 iOS / iPadOS 上，广告 SDK 可能自动采集设备标识符，目的为广告投放、效果统计与反作弊，方式为 SDK 自动采集，范围为与广告服务相关的必要参数。IDFA 仅在您授权 App Tracking Transparency（ATT）后使用。macOS 不为此目的集成广告 SDK。在 Android 中国大陆分发版本接入广告服务后，相关 SDK（如穿山甲广告 SDK、优量汇 Android SDK、抖音SDK（安卓版）等）可能采集 OAID、Android ID 等设备标识符，目的为广告投放、效果统计、反作弊与 SDK 稳定性，方式为 SDK 自动采集，范围为与广告服务相关的必要参数，具体以您的同意及本隐私政策第 2.3 节为准。
  • IP 地址：在 iOS / iPadOS 上，Google AdMob 或穿山甲 / 优量汇等广告 SDK 展示广告时可能自动采集 IP 地址；在 Android 中国大陆分发版本接入广告后，穿山甲广告 SDK、优量汇 Android SDK、抖音SDK（安卓版）等可能自动采集 IP 地址，目的为广告加载、反作弊与 SDK 稳定性，方式为 SDK 自动采集，范围为与广告服务相关的网络地址。应用判定广告地区时，亦可能将 IP 地址发送至 ipinfo.io，目的为选择广告服务商，方式为本应用发起的网络请求，范围为该服务返回的国家或地区代码。
  • 传感器列表、特定类型传感器（如加速度计、陀螺仪等）：在 iOS / iPadOS 上展示 AdMob 广告时，Google AdMob SDK 可能进行同类采集。我们已配置穿山甲 SDK 不将位置信息用于广告。
  • 位置信息：我们不以广告投放为目的收集位置信息，亦不为广告定向申请位置权限。
  • 剪切板：本应用仅在您主动触发复制操作时，将您选择的内容写入系统剪切板（如复制我们的客服邮箱），不会在后台读取或上传剪切板内容。
  • 封面查询用游戏标题：获取封面时，我们可能将基于 ROM 文件名清理后的游戏标题发送至 IGDB 及 Apple iTunes Search API，目的为检索公开可用的封面图片，方式为本应用发起的网络请求，范围仅为游戏标题文本，不包含 ROM 文件内容。
  • 图片与相册：在 iOS / iPadOS 上，当您在游戏中截图时，应用可能请求相册写入权限以将图片保存至相册；若您拒绝授权，截图将保存至应用存储空间。在 Android 上，截图默认保存在应用存储空间；若您授权相关权限，亦可保存至相册。本应用不会在后台批量读取您的相册。
  • 麦克风：仅在您运行的游戏或核心需要麦克风输入时使用（如部分 NDS 游戏）；音频在本地用于模拟，不会上传至我们的服务器。
  • 广告中的视频与音频：在 iOS / iPadOS（及 Android 接入广告后）上，激励视频等广告素材由第三方广告 SDK 在您观看广告时加载播放；我们不会通过广告采集或上传您的个人音视频文件。
  • 游戏 ROM 与存档：在设备本地处理；在 iOS / iPadOS / macOS 上，您启用同步时可存储于您的 iCloud 容器。Android 版本当前仅在设备本地保存存档。我们不会将您的 ROM 库上传至我们的服务器。
  • 日历、短信、通讯录、本机号码、通话记录：不收集。

  • 设备信息（如设备型号、系统版本及 IDFV）：目的为广告投放、效果统计与反作弊；方式为 SDK 自动采集；范围为与广告服务相关的必要设备参数。
  • 广告标识符（iOS 上在系统允许范围内可能涉及广告标识相关能力）：目的为广告衡量与反作弊；方式为 SDK 自动采集；范围为设备分配的广告相关标识。您可在系统设置中限制广告跟踪或重置广告标识符。
  • 网络与诊断信息（如 IP 地址、网络类型、与广告服务相关的崩溃或诊断信号）：目的为广告加载、反作弊与 SDK 稳定性；方式为 SDK 自动采集；范围为与广告服务直接相关的数据。
  • 传感器列表与特定类型传感器（如加速度计、陀螺仪等）：目的为广告反作弊、广告效果优化与设备兼容性判断；方式为 SDK 通过系统接口自动读取；范围为与广告服务及反作弊直接相关的传感器类型与列表信息。

iOS / iPadOS 在上述 AdMob 场景下，当前不会在展示 AdMob 广告前主动弹出 App Tracking Transparency（ATT）跟踪授权弹窗；您可在 iOS 系统「设置 → 隐私与安全性 → Apple 广告」等路径中限制个性化广告或重置广告标识符。
