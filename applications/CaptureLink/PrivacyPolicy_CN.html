CaptureLink 隐私政策

更新日期：2026.8.26

CaptureLink（显示名称可能为 Capture Link）是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的游戏采集与远程游玩工具类应用。本隐私政策适用于 iOS、iPadOS、macOS、visionOS、Android 与 HarmonyOS 平台的 CaptureLink，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私政策与《CaptureLink 用户协议》共同构成您使用本服务的完整法律文件。

CaptureLink 的核心功能包括通过采集卡或屏幕采集获取游戏画面、本地录制与推流、以及连接 PlayStation 主机进行远程游玩。视频、音频、截图与录像主要在您的设备本地处理；我们不会将您的游戏画面库上传至我们的服务器。本服务当前不集成第三方广告 SDK，亦不以展示广告作为核心功能的解锁条件。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 核心应用功能。 为实现采集、录制、推流、远程游玩、手柄支持、网络诊断等功能，我们会在您使用相关功能时，通过系统接口调用相机、麦克风、屏幕录制、本地网络、蓝牙、存储、语音识别、运动传感器及定位（用于读取 Wi-Fi 名称与信号强度等网络诊断信息）等能力。您采集、录制或串流的画面与音频主要在设备本地处理；在您主动发起的推流、远程游玩连接或第三方平台授权过程中，相关数据会按照功能需要发送至您选择的服务或主机。我们不会将上述内容用于识别您的个人身份，亦不会将完整录像库上传至我们的服务器。

1.2 本地偏好设置与运行状态。 我们会在您的设备本地保存部分设置（如采集参数、串流偏好、Pro 权益状态标记、主机列表与界面偏好等），用于应用正常运行。在 Apple 平台上，您可选择通过 iCloud 键值存储（KVS）同步部分非敏感设置；同步数据存储于您的 iCloud 账户，并按照 Apple iCloud 政策管理。

1.3 主机注册与远程游玩凭证。 若您使用远程游玩功能，主机注册信息、配对密钥、PIN 及相关连接参数主要保存在设备本地安全存储中（如 Apple 钥匙串或 Android / HarmonyOS 系统密钥库）。若您选择登录 PlayStation Network（PSN），OAuth 访问令牌、刷新令牌及 PSN Account ID 等认证信息将保存在设备安全存储中，并传输至 Sony 相关服务器以完成登录与远程游玩。我们不运营 PSN，其数据处理受 Sony 政策约束。

1.4 推流平台 OAuth（可选）。 若您选择连接 Twitch、YouTube、Facebook、哔哩哔哩等推流平台，相关 OAuth 令牌、频道或账户标识将保存在设备本地，并传输至相应平台 API 以获取推流密钥或完成推流配置。我们不会存储您的第三方平台账户密码。

1.5 小组件与跨设备共享（Apple 平台，如适用）。 为在小组件、Handoff 或 App Group 中展示主机在线状态、快速连接入口或运行统计，相关摘要信息可能通过 App Group 在用户设备上的本应用与扩展组件之间共享，不会上传至我们的服务器。

1.6 实时字幕与语音命令（如适用）。 若您启用实时字幕或语音命令，语音识别可能在设备本地通过系统能力处理；我们不会将识别结果上传至我们的服务器用于用户画像或广告投放。

1.7 网络诊断。 为评估连接质量、发现本地主机或进行端口检测，应用可能读取 Wi-Fi 名称、信号强度、本地 IP 地址及网络连通性信息。上述信息主要用于本地诊断与功能实现，不会用于广告投放。

1.8 我们不会做的事。 本服务不要求您注册我们运营的应用内账号。我们不提供、不分发任何受版权保护的游戏内容。我们当前不集成 Firebase、友盟、穿山甲、AdMob 等第三方广告或用户行为分析 SDK。我们不会在后台批量读取您的相册，亦不会读取您的通讯录、短信、通话记录或本机号码。

1.9 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • 音视频与画面内容：在您使用采集、录制、推流或远程游玩时本地处理；推流或连接主机时按功能需要发送至您选择的服务，目的为实现相关功能，方式为您主动使用功能时处理，范围为当前会话相关的画面与音频。
  • 截图与录像文件：保存在设备本地或您授权的文件夹/相册，目的为保存您的创作内容，方式为本地写入，范围为您主动保存的文件。
  • 主机与配对信息：保存在设备安全存储中，目的为主机发现、注册、配对与连接，方式为本地存储及按功能需要与主机通信，范围为主机名称、地址、配对密钥等必要参数。
  • PSN / 推流平台 OAuth 令牌：保存在设备安全存储中，目的为完成第三方登录与 API 调用，方式为您主动授权后存储与传输，范围为认证所需令牌与账户标识。
  • 网络与设备信息（如 Wi-Fi 名称、信号强度、本地 IP、设备型号、系统版本）：目的为网络诊断、功能兼容与连接稳定性，方式为系统接口读取，范围为功能实现所需参数。
  • 购买与订阅状态：由应用商店返回购买确认与产品标识，目的为解锁 Pro 权益，方式为应用商店验证，范围为订单状态与产品 ID。
  • 语音识别文本（如适用）：在设备本地处理，目的为实时字幕或语音命令，方式为系统语音识别能力，范围为当前识别会话内容。
  • 剪切板：本应用仅在您主动触发复制操作时，将您选择的内容写入系统剪切板（如复制客服邮箱），不会在后台读取或上传剪切板内容。
  • 日历、短信、通讯录、本机号码、通话记录：不收集。
  • 广告标识符（IDFA / OAID 等）：本服务当前不集成广告 SDK，不为广告投放目的收集上述标识符。

对于由 Apple、Google、华为、Sony 或推流平台等第三方处理的信息，您也可通过相应提供方的设置或政策行使权利。

6. 信息存储地点及期限

6.1 您通过本应用处理的画面、音频、截图、录像及模拟器/采集设置，主要在您的设备本地处理；在 Apple 平台上，您启用同步时，部分非敏感设置可存储于您的 iCloud 容器；除非您主动发起推流、远程游玩连接或第三方平台授权。

6.2 支付、PSN 登录、推流平台 OAuth 等相关数据由 Apple、Google、华为、Sony、Twitch、Google、Facebook、哔哩哔哩及其服务提供商按照各自政策在相应基础设施中存储和处理，可能涉及您所在国家或地区以外的服务器。

6.3 除法律法规另有规定外，我们对信息的保存期限为为实现处理目的所必要的最短时间。
