关于 iEmulator 与隐私的声明

更新日期：2026.7.29

iEmulator 是由 为敢技术（深圳）有限公司（以下简称「我们」）为您提供的，用于在 Apple 平台上进行复古游戏模拟的应用。本隐私声明适用于 iOS、iPadOS 与 macOS 平台的 iEmulator，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

本隐私声明与《iEmulator 用户协议》共同构成您使用本服务的完整法律文件。

在 iOS / iPadOS 版本中，非 VIP 用户适用广告与使用次数相关规则。当系统判定您所在地区为中国大陆时，广告通过穿山甲 GroMore 聚合服务提供（含穿山甲与优量汇）；在其他地区使用 Google AdMob。VIP 通过 Apple 内购提供。macOS 版本不展示广告、不设每日启动次数限制，但启动游戏需要有效的 VIP 订阅。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 核心应用功能。 为实现游戏模拟、存档管理、联机、手柄支持等功能，我们会在您使用相关功能时，通过系统接口调用蓝牙、麦克风、本地网络及 iCloud 能力。在 iOS / iPadOS 上，保存游戏内截图时可能请求相册写入权限。您导入的游戏 ROM、存档、截图等内容在设备本地或您主动选择的服务中处理。在您主动发起的联机过程中，游戏数据可能在您的设备与本地网络中的其他玩家设备之间直接传输。可选的 iCloud 存档同步与 RetroAchievements 仅向 VIP 订阅用户开放。我们不会将上述数据用于识别您的个人身份。

1.2 本地偏好设置。 我们会在您的设备本地保存部分设置（如主题、使用次数配额、VIP 状态标记及模拟器偏好等），用于应用正常运行。

1.3 广告地区判定（仅 iOS / iPadOS）。 为选择适当的广告服务商，应用可能向第三方 IP 地理位置服务（ipinfo.io）请求您的国家或地区代码。该请求可能向该服务暴露您的 IP 地址。若请求失败或尚无已存储值，我们可能回退至设备语言（例如简体中文对应中国大陆）。所得地区代码保存在您的设备本地。

1.4 封面查询。 为展示游戏封面，应用可能将基于 ROM 文件名清理后的游戏标题发送至 IGDB（通过 Twitch OAuth）及 Apple iTunes Search API 等第三方服务。我们不会发送 ROM 文件内容。获取的封面图片缓存在您的设备本地。

1.5 可选的第三方登录。 若您为 VIP 订阅用户并选择使用 RetroAchievements，您的用户名与认证令牌将保存在设备钥匙串中，并传输至 RetroAchievements 服务器以完成登录与成就同步。我们不运营 RetroAchievements，其数据处理受其自身政策约束。

1.6 我们不会做的事。 本服务不要求您注册应用内账号。在 iOS / iPadOS 上，非 VIP 用户可在使用次数限制内使用核心模拟功能。在 macOS 上，启动游戏需要有效的 VIP 订阅。我们不提供、不包含且不分发任何受版权保护的游戏 ROM 或其他第三方内容。

1.7 为满足个人信息保护法规及应用商店合规要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用不会为所述目的主动采集、读取或上传该类型信息。

  • 设备标识符（IDFV；经授权时的 IDFA）：在 iOS / iPadOS 上，广告 SDK 可能自动采集设备标识符，目的为广告投放、效果统计与反作弊，方式为 SDK 自动采集，范围为与广告服务相关的必要参数。IDFA 仅在您授权 App Tracking Transparency（ATT）后使用。macOS 版本不为此目的集成广告 SDK。
  • IP 地址：在 iOS / iPadOS 上，Google AdMob 或穿山甲 / 优量汇等广告 SDK 展示广告时可能自动采集 IP 地址，目的为广告加载、反作弊与 SDK 稳定性，方式为 SDK 自动采集，范围为与广告服务相关的网络地址。应用判定广告地区时，亦可能将 IP 地址发送至 ipinfo.io，目的为选择广告服务商，方式为本应用发起的网络请求，范围为该服务返回的国家或地区代码。
  • 传感器列表、特定类型传感器（如加速度计、陀螺仪等）：在 iOS / iPadOS 上展示 AdMob 广告时，Google AdMob SDK 可能进行同类采集。我们已配置穿山甲 SDK 不将位置信息用于广告。
  • 位置信息：我们不以广告投放为目的收集位置信息，亦不为广告定向申请位置权限。
  • 剪切板：本应用仅在您主动触发复制操作时，将您选择的内容写入系统剪切板（如复制我们的客服邮箱），不会在后台读取或上传剪切板内容。
  • 封面查询用游戏标题：获取封面时，我们可能将基于 ROM 文件名清理后的游戏标题发送至 IGDB 及 Apple iTunes Search API，目的为检索公开可用的封面图片，方式为本应用发起的网络请求，范围仅为游戏标题文本，不包含 ROM 文件内容。
  • 图片与相册：在 iOS / iPadOS 上，当您在游戏中截图时，应用可能请求相册写入权限以将图片保存至相册；若您拒绝授权，截图将保存至应用存储空间。本应用不会在后台批量读取您的相册。
  • 麦克风：仅在您运行的游戏或核心需要麦克风输入时使用（如部分 NDS 游戏）；音频在本地用于模拟，不会上传至我们的服务器。
  • 广告中的视频与音频：在 iOS / iPadOS 上，激励视频等广告素材由第三方广告 SDK 在您观看广告时加载播放；我们不会通过广告采集或上传您的个人音视频文件。
  • 游戏 ROM 与存档：在设备本地处理，或在您启用同步时存储于您的 iCloud 容器；我们不会将您的 ROM 库上传至我们的服务器。
  • 日历、短信、通讯录、本机号码、通话记录：不收集。
2. 第三方 SDK 及广告服务

2.1 Google AdMob 广告（iOS / iPadOS：判定地区非中国大陆）

在上述场景下，本应用集成 Google Mobile Ads SDK（AdMob），用于展示广告（含开屏、激励等形态）、统计广告效果及防范作弊。AdMob 由 Google LLC 提供，可能自动采集以下信息：

  • 设备信息（如设备型号、系统版本及 IDFV）：目的为广告投放、效果统计与反作弊；方式为 SDK 自动采集；范围为与广告服务相关的必要设备参数。
  • 广告标识符（iOS 上在系统允许范围内可能涉及广告标识相关能力）：目的为广告衡量与反作弊；方式为 SDK 自动采集；范围为设备分配的广告相关标识。您可在系统设置中限制广告跟踪或重置广告标识符。
  • 网络与诊断信息（如 IP 地址、网络类型、与广告服务相关的崩溃或诊断信号）：目的为广告加载、反作弊与 SDK 稳定性；方式为 SDK 自动采集；范围为与广告服务直接相关的数据。
  • 传感器列表与特定类型传感器（如加速度计、陀螺仪等）：目的为广告反作弊、广告效果优化与设备兼容性判断；方式为 SDK 通过系统接口自动读取；范围为与广告服务及反作弊直接相关的传感器类型与列表信息。

iOS / iPadOS 在上述 AdMob 场景下，当前不会在展示 AdMob 广告前主动弹出 App Tracking Transparency（ATT）跟踪授权弹窗；您可在 iOS 系统「设置 → 隐私与安全性 → Apple 广告」等路径中限制个性化广告或重置广告标识符。

Google 隐私政策：https://policies.google.com/privacy

在您已订阅 VIP 且权益有效的范围内，相关版本可不向您展示广告。

2.2 穿山甲 GroMore 聚合广告（iOS / iPadOS：判定地区为中国大陆）

在上述场景下，本应用不使用 AdMob，而通过 穿山甲 GroMore 聚合广告服务接入以下广告网络：

  • 穿山甲（北京巨量引擎网络技术有限公司）
  • 优量汇（深圳市腾讯计算机系统有限公司，腾讯广告）

GroMore 会根据您在应用内请求的广告位，在穿山甲与优量汇等已接入的广告网络之间进行调度与填充。上述 SDK 会通过自动采集方式收集以下信息：

  • 设备信息（如设备型号、操作系统版本；iOS 上可能涉及 IDFV，并在您授权 ATT 时可能涉及 IDFA）：目的为广告投放、效果统计与反作弊；方式为 SDK 自动采集；范围为与广告服务相关的必要设备参数。
  • 网络状态信息（如网络类型、连接状态）：目的为广告加载与反作弊；方式为 SDK 自动采集；范围为网络连接状态相关数据。
  • 广告交互与诊断信息（如广告展示、点击、转化及 SDK 运行日志）：目的为广告效果衡量、结算与故障排查；方式为 SDK 自动采集；范围为与广告服务直接相关的数据。
  • IP 地址：目的为广告加载、效果统计与反作弊；方式为 SDK 在网络通信过程中自动获取；范围为与广告服务直接相关的网络地址信息。

各 SDK 提供方及隐私政策链接：

  • 穿山甲 / GroMore：https://www.csjplatform.com/privacy/partner
  • 优量汇（腾讯广告）：https://e.qq.com/dev/help_detail.html?cid=2005&pid=5983

在 iOS / iPadOS（中国大陆广告场景），我们通过穿山甲 SDK 隐私配置关闭将位置信息用于广告的路径；在初始化穿山甲 SDK 前，若系统尚未记录您的选择，可能向您弹出 App Tracking Transparency（ATT） 授权请求，以决定是否可使用 IDFA——若您拒绝或限制跟踪，我们将在 SDK 侧限制 IDFA 的使用。VIP 用户不展示广告。

第三方 SDK 可能将上述信息传输至其服务器进行处理与存储，具体规则请参见各提供方的隐私政策。

3. 应用内购买与订阅

iOS / iPadOS 与 macOS 版本均通过 Apple 内购（StoreKit）提供 VIP 订阅及买断。支付流程由 Apple 完成，我们不会收集或存储您的完整支付卡号等敏感支付凭证。我们仅接收购买确认、订阅状态与产品标识，用于在您的设备上解锁 VIP 权益（如在 iOS / iPadOS 上免广告、无限次启动、主题与界面自定义、iCloud 存档同步及 RetroAchievements 访问权限等）。您可在 Apple 账户设置中管理或取消订阅。

Apple 对支付相关数据的处理受其政策约束：https://www.apple.com/legal/privacy/

在 iOS / iPadOS 上，非 VIP 用户可能受到每日免费启动次数限制，可通过观看激励视频获得额外次数。在 macOS 上，启动游戏需要有效的 VIP 订阅。

网络
