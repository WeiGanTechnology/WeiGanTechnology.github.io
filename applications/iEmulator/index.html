1. 服务说明

1.1 iEmulator 是一款基于 Libretro 框架的复古游戏模拟器应用，主要功能包括但不限于：导入并运行兼容的游戏 ROM 文件与压缩包；即时存档与游戏内存档；面向 VIP 订阅用户的 iCloud 存档同步；基于本地网络的回滚联机；面向 VIP 订阅用户的 RetroAchievements 成就集成；屏幕虚拟按键与外部游戏手柄支持；手柄皮肤与配置工具；金手指与核心选项；为需要 BIOS 的平台导入 BIOS；以及在 iOS / iPadOS 上的分享、小组件与缩略图扩展等。具体功能以您所使用版本、设备、操作系统及您自行提供的游戏文件为准，我们可能不时更新、调整或下线部分功能。

1.2 使用蓝牙手柄、麦克风、本地网络、iCloud 等能力时，您需授予相应系统权限。在 iOS / iPadOS 上，保存游戏内截图时可能请求相册写入权限。拒绝授权可能导致相关功能无法使用，但不影响您使用不依赖该权限的其他功能（以实际版本为准）。

1.3 本服务不要求您注册应用内账号。在 iOS / iPadOS 上，非 VIP 用户可在第 1.4 节所述使用次数限制内使用核心模拟功能。在 macOS 上，启动游戏需要有效的 VIP 订阅。在 Android 上，核心模拟功能不要求注册账号。我们不提供、不包含且不分发任何受版权保护的游戏 ROM、BIOS 或其他第三方受保护内容。您须自行提供合法获取的游戏文件。

1.4 商业化规则因平台而异。在 iOS / iPadOS 上，非 VIP 用户适用每日启动次数限制，并可通过观看激励视频获得额外次数，详见下文第 4、5 节；Controller Hub 功能亦受相同次数规则约束。当系统判定您所在地区为中国大陆时，广告通过穿山甲 GroMore 聚合服务提供（含穿山甲与优量汇）；在其他地区使用 Google AdMob。macOS 版本不展示广告、不设每日启动次数限制，但启动游戏、使用 Controller Hub 及访问部分其他高级功能需要有效的 VIP 订阅。两个平台的 VIP 均通过 Apple 内购提供。

1.5 在 Android 上，通过 Google Play 等渠道分发时，Premium / VIP 权益通过 Google Play 结算等方式解锁；通过 OPPO、vivo、360 手机助手等国内应用商店分发时，非 Premium / VIP 用户每日可免费启动游戏 2 次，观看激励视频可额外获得 2 次启动机会，广告通过穿山甲 GroMore 聚合服务提供（含穿山甲广告 SDK、优量汇 Android SDK 与抖音SDK（安卓版）等，详见《iEmulator 隐私政策》第 2.3.1 至 2.3.3 节）。在初始化任何广告 SDK 前，我们会征得您的同意。若您选择「不同意，仅使用核心功能」，我们不会初始化广告 SDK；游戏启动、游戏库（校准）及每日启动配额需在同意广告服务后使用。

1.6 在 HarmonyOS 上，通过华为应用市场（AppGallery）分发的版本，Premium / VIP 权益可通过华为应用内购买（IAP）解锁；非 VIP 用户可能适用每日启动次数限制，并可通过观看激励视频获得额外次数。广告可能通过穿山甲 GroMore 等第三方服务提供（详见《iEmulator 隐私政策》）。在初始化任何广告 SDK 前，我们会征得您的同意。具体产品、价格及权益范围以应用内展示为准。
