关于 iNFCi 与隐私的声明

更新日期：2026.7.14

iNFCi 是由 为敢技术（深圳）有限公司（以下简称“我们”）为您提供的，用于 NFC 读写及蓝牙设备连接等功能的应用。本隐私声明适用于 iOS 与 Android 平台的 iNFCi，并说明我们如何处理您的个人信息。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

根据您获取应用的渠道、操作系统及设备语言环境，广告与支付相关能力可能有所不同：当设备系统首选语言不是简体中文时，iOS App Store 版与 Android Google Play 版使用 Google AdMob 与各自应用商店支付；当设备系统首选语言为简体中文时，iOS App Store 版使用穿山甲 GroMore 聚合广告（含穿山甲与优量汇），并仍通过 Apple 内购提供 VIP；中国大陆应用商店版（Android）亦使用 GroMore 聚合广告，且不包含 Google Play 结算。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 我们为您提供了基本功能服务和全量功能服务，您可以前往读写菜单进行选择，不同设备、系统或版本其路径可能存在差异，具体以您当前使用的设备为准。在基本功能服务下，我们不会为实现 NFC 读写等基本能力而要求您注册账号，亦不会因此主动向我们的服务器上传可识别您个人身份的信息；我们不会提供、不包含且不分发任何受版权保护的游戏文件等其他附加功能，这可能会影响您的使用体验。

1.2 为实现蓝牙设备连接、固件升级、二维码扫描、局域网设备更新等核心功能，我们会在您使用相关功能时，通过系统接口调用蓝牙、NFC、相机和网络能力。相关数据仅在本地或与您选择连接的设备之间处理，不会用于识别您的个人身份。

1.3 我们会在您的设备本地保存部分设置（如主题、使用次数配额、VIP 状态标记等），用于应用正常运行。

1.4 为满足个人信息保护法规及应用商店合规检测要求，我们按类型明示本应用可能涉及的个人信息处理情况。下表所列「目的」「方式」「范围」仅适用于标注的适用版本或场景；标注为「不收集」的类型，表示本应用自身及我们已配置限制的第三方 SDK 均不会主动采集、读取或上传该类型信息。

  • Android ID：中国大陆应用商店版（Android）不收集（广告 SDK 侧已关闭）；Android Google Play 版在展示 AdMob 广告时，可能由 Google AdMob SDK 自动采集，目的为广告投放、效果统计与反作弊，方式为 SDK 自动采集，范围为与广告服务相关的设备标识。
  • ICCID、IMSI、MEID、本机号码、硬件序列号：不收集。
  • IMEI：中国大陆应用商店版（Android）不收集（广告 SDK 侧已关闭）；其他版本不通过本应用主动采集。
  • MAC 地址：中国大陆应用商店版（Android）不收集（广告 SDK 侧已关闭）；本应用蓝牙功能仅用于连接您选择的外设，不会将 MAC 地址上传至我们的服务器。
  • OAID（开放匿名设备标识符）：仅中国大陆应用商店版（Android）在您同意本隐私政策后，由穿山甲 / 优量汇等广告 SDK 自动采集，目的为广告投放、效果统计与反作弊，方式为 SDK 自动采集，范围为设备分配给广告服务的匿名标识符。
  • 传感器列表、特定类型传感器（如加速度计、陀螺仪、光线传感器等设备上已公开类型的传感器信息）：中国大陆应用商店版（Android）不收集（已通过穿山甲 SDK「motion_info」配置及优量汇 SDK「sensor_ts」配置关闭采集）；本应用 NFC、蓝牙等核心功能不依赖读取传感器列表。Android Google Play 版展示 AdMob 广告时，Google AdMob SDK 可能进行同类采集，规则见下文第 2.1 节。
  • 位置信息、定位：中国大陆应用商店版（Android）广告侧不采集位置信息（广告 SDK 侧已关闭，应用清单已移除广告所需粗略位置权限）；在 Android 11 及以下版本，系统可能要求授予位置权限后才能进行蓝牙设备扫描，该权限仅用于满足系统对蓝牙扫描的要求，相关数据不上传至我们的服务器，与广告投放无关。iOS在您主动使用地图、标签坐标等功能时可能申请位置权限，数据仅用于您主动使用的功能。
  • Wi‑Fi 列表、SSID、BSSID、Wi‑Fi 状态：中国大陆应用商店版（Android）不收集（广告 SDK 侧已关闭 Wi‑Fi 状态读取）；本应用不采集 Wi‑Fi 列表、SSID 或 BSSID。
  • 软件安装列表（软件列表）：中国大陆应用商店版（Android）不收集（广告 SDK 侧已关闭，应用清单已移除「查询所有已安装应用」权限声明）。
  • IP 地址：Android Google Play 版展示 AdMob 广告时，可能由 Google AdMob SDK 自动采集，目的为广告加载、反作弊与 SDK 稳定性，方式为 SDK 自动采集，范围为与广告服务直接相关的网络地址信息；中国大陆应用商店版（Android）在您同意并初始化广告 SDK 后，穿山甲 / 优量汇等广告 SDK 在广告请求与效果统计过程中可能自动获取与广告服务相关的 IP 地址信息，目的为广告加载、效果统计与反作弊，方式为 SDK 在网络通信过程中自动获取，范围为与广告服务直接相关的网络地址信息。
  • 剪切板：本应用仅在您主动触发复制操作时，将您选择的内容写入系统剪切板（如复制设备标识文本），不会在后台读取或上传剪切板内容。
  • 图片：仅在您主动从相册选择图片识别二维码，或在相关功能中将二维码保存至相册时访问；图像在本地处理，不会上传至我们的服务器。
  • 摄像头：仅在您主动使用二维码扫描功能时调用；图像在本地解码处理，不会上传至我们的服务器。
  • 视频、音频：激励视频等广告素材由第三方广告 SDK 在您观看广告时加载播放；本应用不采集、不上传您的个人视频或音频文件，不访问麦克风。
  • 日历、短信、通讯录、系统账户信息、通话记录：不收集。

上述清单中涉及第三方广告 SDK 的采集行为，均仅在您点击隐私政策弹窗「同意」后（中国大陆应用商店版 Android）或在使用相应广告服务时（其他版本）发生；若您选择「不同意，仅使用核心功能」，我们不会初始化广告 SDK，相关采集亦不会发生。

2. 第三方 SDK 及广告服务

2.1 Google AdMob 广告（iOS：系统首选语言非简体中文；Android：Google Play 版）

本节不适用于中国大陆应用商店版（Android）。该版本不使用 Google AdMob，亦不由本应用通过 AdMob 采集 Android ID；相关说明见下文第 2.2 节。

在上述场景下，本应用集成 Google Mobile Ads SDK（AdMob），用于展示广告（含开屏、横幅、激励等形态）、统计广告效果及防范作弊。AdMob 由 Google LLC 提供，可能自动采集以下信息：

  • 设备信息（如设备型号、系统版本；Android 上可能涉及 Android ID，iOS 上可能涉及 IDFV 等设备标识符）：目的为广告投放、效果统计与反作弊；方式为 SDK 自动采集；范围为与广告服务相关的必要设备参数。
  • 广告标识符（Android 上的 Google 广告 ID；iOS 上在系统允许范围内可能涉及广告标识相关能力）：目的为广告衡量与反作弊；方式为 SDK 自动采集；范围为设备分配的广告相关标识。您可在系统设置中限制广告跟踪或重置广告标识符。
  • 网络与诊断信息（如 IP 地址、网络类型、与广告服务相关的崩溃或诊断信号）：目的为广告加载、反作弊与 SDK 稳定性；方式为 SDK 自动采集；范围为与广告服务直接相关的数据。
  • 传感器列表与特定类型传感器（如加速度计、陀螺仪等设备上已公开类型的传感器信息）：目的为广告反作弊、广告效果优化与设备兼容性判断；方式为 SDK 通过系统接口自动读取；范围为与广告服务及反作弊直接相关的传感器类型与列表信息。

在适用法律要求的地区（如欧洲经济区、英国、瑞士等），Android Google Play 版可能通过 Google User Messaging Platform（UMP） 在展示个性化广告前征求您的同意；您也可在该版本应用内相关设置中查看或调整广告隐私选项（视地区而定）。iOS 在上述 AdMob 场景下不使用 UMP，且当前不会在展示 AdMob 广告前主动弹出 App Tracking Transparency（ATT）跟踪授权弹窗；您可在 iOS 系统「设置 → 隐私与安全性 → Apple 广告」等路径中限制个性化广告或重置广告标识符。

Google 隐私政策：https://policies.google.com/privacy

在您已订阅 VIP 且权益有效的范围内，相关版本可不向您展示广告。

3. 应用内购买与订阅

iOS（App Store）版本无论系统语言环境，均通过 Apple 内购（StoreKit）提供可选 VIP 订阅及买断。Android（Google Play）版本通过 Google Play 结算提供同类权益。支付流程由 Apple 或 Google 完成，我们不会收集或存储您的完整支付卡号等敏感支付凭证。我们仅接收购买确认、订阅状态与产品标识，用于在您的设备上解锁 VIP 权益（如免广告、主题与扩展使用次数等）。您可在 Apple 或 Google 账户设置中管理或取消订阅。

Apple 对支付相关数据的处理受其政策约束：https://www.apple.com/legal/privacy/

非 VIP 用户可能受到每日免费使用次数限制，可通过观看激励视频获得额外次数（iOS 与启用商业化的 Android 版本均可能适用）。

中国大陆应用商店版（Android）不包含 Google Play 结算；免费使用次数等规则以该版本应用内说明为准，可能包含激励视频广告。

本服务在运行过程中可能申请以下权限。我们会在系统权限弹窗或首次启动说明中征求您的同意；您拒绝授权仅会影响对应功能。

NFC

用于读写 NFC 标签与卡片（iOS 与 Android）。

蓝牙（发现与连接）

位置信息

Android：在 Android 11 及以下版本，操作系统可能要求授予位置权限后才能进行蓝牙设备扫描；该权限用于满足系统对蓝牙扫描的要求，与广告投放无关（国内版已在应用清单中移除广告 SDK 所需的粗略位置权限声明）。iOS：在您使用地图、标签坐标等相关功能时可能申请位置权限；相关数据用于您主动使用的功能，与广告投放无直接关联。

相册 / 照片（iOS）

用于您主动从相册选择图片识别二维码，或在相关功能中将二维码保存至相册；仅在您触发相关功能时访问，不会在后台批量读取您的相册。

Face ID / Touch ID（iOS）

用于您启用应用锁或相关安全验证功能时的本地身份核验；生物识别信息由系统处理，我们不会采集或存储您的生物特征数据。

相机

用于您主动使用二维码扫描功能；图像在本地解码处理，不会上传至我们的服务器（iOS 与 Android）。

网络与本地网络

用于广告加载、应用商店内购、您主动发起的固件或内容下载，以及局域网 OTA 等设备通信（iOS 与 Android）。

通知（Android）

用于在您授权后展示与蓝牙连接、固件更新等相关的可选状态通知。

前台服务（Android）

用于在您主动使用蓝牙连接、固件升级等相关功能时，保持连接任务稳定运行。
