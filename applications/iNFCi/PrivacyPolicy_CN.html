关于iNFCi与隐私的声明

更新日期：2026.7.13

iNFCi 是由 为敢技术（深圳）有限公司（以下简称“我们”）为您提供的，用于NFC读写的应用。本隐私声明由我们为处理您的个人信息而制定。

我们非常重视您的个人信息和隐私保护，将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。

1.1 我们为您提供了基本功能服务和全量功能服务，您可以前往读写菜单进行选择，不同设备或版本其路径可能存在差异，具体以您当前使用的设备为准。在基本功能服务下不收集个人信息，仅提供NFC读写的基本功能，不提供、不包含且不分发任何受版权保护的游戏文件等其他附加功能，这可能会影响您的使用体验。

1.2 为实现蓝牙设备连接、固件升级、二维码扫描等核心功能，我们会在您使用相关功能时，通过系统接口调用蓝牙、NFC、相机和网络能力。相关数据仅在本地或与您选择连接的设备之间处理，不会用于识别您的个人身份。

2. 第三方 SDK 及广告服务

为向您展示广告、统计广告效果及防范作弊，在您同意本隐私政策后，我们会初始化第三方广告 SDK「穿山甲」（北京巨量引擎网络技术有限公司提供）。该 SDK 可能通过自动采集方式收集以下信息：

  • 设备信息（如设备型号、操作系统版本、OAID、Android ID）：目的为广告投放、效果统计与反作弊；方式为 SDK 自动采集；范围为与广告服务相关的必要设备参数。
  • 网络状态信息（如网络类型、信号强度）：目的为广告加载与反作弊；方式为 SDK 自动采集；范围为网络连接状态相关数据。

我们已在应用侧通过穿山甲 SDK 隐私配置接口关闭对以下信息的采集，SDK 不会读取：

  • 设备 MAC 地址
  • 软件安装列表
  • IMEI 等电话状态标识符
  • 精确位置信息

穿山甲隐私政策：https://www.csjplatform.com/privacy/partner

广告 SDK 仅在您同意本隐私政策后初始化；若您选择不同意，我们不会初始化广告 SDK，您仍可继续使用不含广告的 NFC 核心功能。

3. 设备权限调用

本服务在运行过程中需要使用以下权限，我们会在使用之前征求您的意见，任何未明确同意使用的权限，均不会被随意调用。

位置（获取设备模糊位置信息）

为了提供更好的体验，我们的应用可能会在您授权后调用以下设备权限：模糊位置，出于隐私保护，强制要求应用在扫描蓝牙设备前必须获取定位权限。如果您拒绝授权，您将无法使用该功能，但不影响应用的其它基础功能。

设备发现和连接（接入蓝牙并使用蓝牙能力）

为了提供更好的体验，我们的应用可能会在您授权后调用以下设备权限：蓝牙权限，用于搜索和连接外部蓝牙设备（如：Pixl.js），以便您可以使用外设进行蓝牙传输数据和蓝牙固件升级。如果您拒绝授权，您将无法使用该功能，但不影响应用的其它基础功能。

您可以随时访问系统“设置”来管理本服务的权限。

4. 管理您的个人信息

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明中“如何联系我们”章节中所述方式与我们取得联系，并行使您的相关权利。

5. 信息存储地点及期限

5.1 我们承诺，除法律法规另有规定外，我们对您的信息的保存期限应当为实现处理目的所必要的最短时间。

5.2 上述信息将会传输并保存至服务器所在国家的服务器。
