2. Device Permission Usage

This service requires the following permissions during operation. We will ask for your consent before using them. Any permission that you have not explicitly agreed to will not be invoked without authorization.

Location (approximate device location)

To provide a better experience, our application may request the following device permission after you grant authorization: Approximate location (ohos.permission.APPROXIMATELY_LOCATION). For privacy protection, the system requires apps to obtain location permission before scanning for Bluetooth devices. If you refuse to grant this permission, you will not be able to use this feature, but other basic functions of the application will not be affected.

Device Discovery and Connection (Bluetooth access and capabilities)

To provide a better experience, our application may request the following device permission after you grant authorization: Bluetooth (ACCESS_BLUETOOTH), used to search for and connect to external Bluetooth devices (such as Pixl.js), so you can use peripherals for Bluetooth data transfer and Bluetooth firmware updates. If you refuse to grant this permission, you will not be able to use this feature, but other basic functions of the application will not be affected.

You can manage permissions for this service at any time in your system Settings.
